# v0.0.7

- **Bigger map** — 1024x640, for continent-sized landmasses.
- **Land wraps** — the forced ocean seam at the map edge is gone, so
  continents wrap across the screen exactly like the water does.
- **Continental shelf** — the ocean slopes from shallow shelf to deep abyss,
  which also keeps the coastline and land relief natural (no cliffs).
