# v0.0.2

- **Richer biomes** — polar ice caps, a snow line, alpine tundra, boreal
  forest, grassland, shrubland, monsoon forest, marsh and mangrove join the
  set (now 20 land biomes), so the land grades naturally across climate bands.
- **Fix** — ocean depth is now continuous (from the elevation field, not a
  stepped distance), so the shallow water no longer shows concentric contour
  streaks.
